Lucky blocks, but for factorio. Defaults to getting gift boxes from science production and killing enemies.

Featuring a full API for mods to add new results.

Made in a few hours for the christmas autocomplete mod jam.

My mods are made 100% by humans, with no computer generated code or graphics.
If you have a mod idea, let me know and I can look into it.
